   - Moyenne globale : **3.17 € / Go** (Médiane : **2.55 € / Go**).
   - **Fournisseur le plus compétitif au Go** : **JamboSIM** (2.90 €/Go), suivi de **Yesim** (2.94 €/Go) et **Ubigi** (3.03 €/Go).
   - **Fournisseur le plus cher au Go** : **4S eSIM** (3.59 €/Go) et **Airalo** (3.38 €/Go, qui capitalise sur sa notoriété).
2. **Impact du Réseau (4G vs 5G)** :

3. **Rechargeabilité (Top-Up)** :
   - **54.15% (2 738 offres)** permettent le rechargement en cours de voyage.
   - Prix moyen quasi-identique (29.06 € vs 29.59 €) : les fournisseurs ne surtaxent pas les forfaits rechargeables.
4. **Segmentation par Durée de Validité** :
   - **7 jours** : 1 679 offres (33.21%) — Prix moyen : **22.90 €**.
   - **15 jours** : 1 667 offres (32.97%) — Prix moyen : **27.34 €**.
   - **30 jours** : 1 710 offres (33.82%) — Prix moyen : **37.50 €**.
5. **Couverture Géographique** :

## 🤖 Partie 1 : Architecture d'Automatisation & Pipeline ETL

Le dossier `scripts/` contient une suite logicielle modulaire prête pour la production :

- `scripts/process_data.py` : Script ETL d'ingestion quotidienne, calcul vectorisé Pandas et export des fichiers JSON optimisés (`summary_stats.json`, `catalog.json`).
- `scripts/automated_daily_etl.py` : Pipeline orienté objet avec schéma de validation, détection proactive des anomalies (devises invalides, prix nuls, doublons SKU), calculs statistiques et publication d'un rapport de santé `data_quality_report.json`.
- `scripts/test_pipeline.py` : Suite de 7 tests unitaires automatisés validant tous les résultats et garantissant l'intégrité mathématique.
- `.github/workflows/daily_etl.yml` : Workflow CI/CD GitHub Actions planifié chaque matin à 04:00 UTC pour exécuter l'ETL, lancer les tests et déployer automatiquement les données à jour sur GitHub Pages.

## ✍️ Partie 2 : Article SEO « Internet en croisière : quelle eSIM choisir ? »

L'article a été conçu pour se positionner **#1 sur Google** face à la concurrence (Wise, MonPetitForfait, Generation Voyage).

### Points forts de la stratégie SEO :
1. **Angle différenciateur à haute valeur ajoutée** : Démystification du piège du **Roaming Maritime Satellite (Cellular at Sea / WMS)** pouvant causer 500 € à 3 000 € de factures surprises.
2. **Clarification technique** : Distinction nette entre la **navigation en haute mer (satellite)** et les **escales aux ports (antennes 4G/5G terrestres)**.
3. **Comparatif exclusif des 3 options** : Wi-Fi du paquebot vs eSIM maritime hybride (GigSky Cruise) vs eSIM régionale d'escale (Airalo, Saily).
4. **Widget Interactif** : Simulateur de recommandation en 3 clics intégré.
5. **Balisage Schema.org FAQPage JSON-LD** : Décrochage de la Position 0 / Featured Snippets dans les résultats de recherche.
6. **Suggestions d'images prêtes pour l'équipe média** : Prompts DALL-E / Midjourney et balises ALT optimisées.
